# Tech Stack Comparison

**Team:** Team 1  
**Week:** 3  

Compare two possible stacks. Do not research everything. Prefer boring and buildable.

## Stack A

- **Stack name:** Vue + TypeScript + Vite / Node.js + TypeScript / MySQL
- **What can we build with this?**  
  A Student Life web application with Student Profile, Semester, Course, Schedule, and Student Job features. The frontend can communicate with a backend API and store persistent data in MySQL.

- **What does the team already know?**  
  The team has experience with web development concepts, GitHub, basic frontend development, and project-based development.

- **What must we learn?**  
  TypeScript syntax and types, Vue component structure, Vite, Node.js backend development, API communication, MySQL database design, and connecting the backend to MySQL.

- **How can we demo it by midterm?**  
  Start with the Student Life Dashboard and build each slice with sample data. The backend and MySQL integration can be added separately after the basic features are working.

- **What could go wrong?**  
  The team may need time to learn TypeScript, Vue, backend API development, and database integration. Connecting all five slices at once could also make the project too large.

- **Simplest first screen or feature:**  
  Student Life Dashboard with five simple navigation cards:
  Student Profile, Semester, Course, Schedule, and Student Job.

## Stack B

- **Stack name:** React + JavaScript + Vite / Node.js + JavaScript / MySQL
- **What can we build with this?**  
  The same Student Life web application with frontend features, a backend API, and persistent MySQL data.

- **What does the team already know?**  
  The team has experience with web development concepts, GitHub, basic frontend development, and project-based development.

- **What must we learn?**  
  React component structure, JavaScript-based frontend development, Vite, Node.js backend development, API communication, MySQL database design, and backend-database integration.

- **How can we demo it by midterm?**  
  Build the Student Life Dashboard first, then implement the five slices independently using sample data before connecting them to the backend and MySQL.

- **What could go wrong?**  
  The project could become too large if the team tries to implement all features and database integration at the same time. React and JavaScript would also require the team to learn a different frontend approach from Stack A.

- **Simplest first screen or feature:**  
  Student Life Dashboard with five simple navigation cards.

## Decision

We choose:

> **Stack A — Vue + TypeScript + Vite / Node.js + TypeScript / MySQL**

Because:

> It gives us one consistent language across the frontend and backend, supports the Student Life MVP, and allows us to develop the five slices independently before connecting them to the backend and MySQL. This keeps the project manageable while still giving us a clear path to a full-stack application.
