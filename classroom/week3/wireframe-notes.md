# Wireframe Notes

**Team:** Team 1
**Week:** 3

A wireframe can be a rough sketch, screenshot, photo, or simple diagram. It does not need to be beautiful.

## Screen / interaction 1

- **Name:** Student Life Dashboard
- **Target user:** University student
- **What the user does:** Opens the Student Life section and chooses what information they want to view.
- **What the screen shows:** Entry points for Student Profile, Semester, Course, Schedule, and Student Job.
- **Sketch/photo link:** [click_me](https://github.com/CapstoneDesign-Fall2026-UlsanCollege/Team1/blob/5982853c098e1fb9e605445df6a752466a237dda/classroom/week3/benweek3.png)

## Screen / interaction 2

- **Name:** Student Information
- **Target user:** University student
- **What the user does:** Selects a Student Life category and views the related information.
- **What the screen shows:** The selected category's information, such as profile details, semester information, courses, or schedule.
- **Sketch/photo link:** [click_me](https://github.com/CapstoneDesign-Fall2026-UlsanCollege/Team1/blob/5982853c098e1fb9e605445df6a752466a237dda/classroom/week3/benweek3.png) 

## Screen / interaction 3

- **Name:** Student Job
- **Target user:** University student looking for a part-time job
- **What the user does:** Opens Student Job and browses available job information.
- **What the screen shows:** Job listings with basic information such as job title, location, working hours, and other relevant details.
- **Sketch/photo link:** [click_me](https://github.com/CapstoneDesign-Fall2026-UlsanCollege/Team1/blob/5982853c098e1fb9e605445df6a752466a237dda/classroom/week3/benweek3.png)

## Easiest first screen to build

We think the easiest first screen/interaction is:

> Student Life Dashboard

Because:

> It mainly provides navigation to the five feature slices without requiring complex backend functionality. It can be built as a simple interface first and connected to the individual features later.
