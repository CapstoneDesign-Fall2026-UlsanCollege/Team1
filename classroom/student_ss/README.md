# StudentHub student screenshots

Live student interface captures collected on October 17–18, 2026 from the Railway deployment. The profile screenshot is deliberately omitted at the user's request because it contains contact details and a student ID; number 02 is therefore unused.

The application scrolls inside its student content panel. Additional scrolled captures show the timetable, filters, and saved-job information below the initial view. Images retain the normal header and bottom navigation. No profile fields, saved jobs, or academic records were modified for these captures.
